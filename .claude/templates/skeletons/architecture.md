## 置き場の決定表

| 置きたいもの | 置き場 |
| ------------ | ------ |
| 特定ドメインの実装 | `src/<domain>/<kind>/` |
| 2 つ以上のドメインが使う実装 | `common/<what-it-does>/` |
| テスト | `tests/` 配下、対象のディレクトリ構造をミラー(`testing.md` 参照) |
| スクリプト | `scripts/` |
| 設定 | {{config_location}} |
| ドキュメント | `docs/` |
| ビルド生成物・静的出力 | {{generated_output_location}}(gitignore 対象) |
| 一時ファイル | リポジトリ外(スクラッチパッド) |
